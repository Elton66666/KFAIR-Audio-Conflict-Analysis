# K-FAIR：Base × TESS/U 完整析因对照

## 实验

使用与 Instruct×TESS 完全一致的 2,400 个同说话人、同词、异情绪真实配对，共运行 9,600 个 `DA/CA、DA/CB、DB/CA、DB/CB` 单元。四分类候选、提示、换流、时间重采样和效应公式均保持不变。95% CI 按 200 个词聚类 bootstrap 10,000 次。

## Base×TESS 结果

| 指标 | 均值 | 95% CI |
|---|---:|---:|
| 连续流主效应 ME_C | -0.099 | [-0.123,-0.073] |
| 离散流主效应 ME_D | 0.037 | [0.019,0.056] |
| 交互效应 | -0.142 | [-0.176,-0.108] |
| 连续流跟随率 | 24.0% | [23.1%,24.8%] |
| 离散流跟随率 | 25.5% | [24.8%,26.2%] |
| 第三类预测率 | 50.6% | [49.7%,51.4%] |
| 匹配单元准确率 | 25.2% | [24.1%,26.3%] |

Base 的匹配准确率与四分类机会水平几乎相同，因此其小幅负 ME_C 不能解释为可靠的“反向情绪依赖”；更合理的结论是，当前固定指令读出下没有形成可用的四分类情绪决策。

![模型与暴露组对照](kfair_model_exposure_matrix.svg)

从 Base 到 Instruct，ME_C 在 RAVDESS/E 上增加约 2.385，在 TESS/U 上增加约 4.527。连续流主导不仅没有局限于公开 SER-SFT 已披露的 RAVDESS，反而在 TESS/U 上更强。

## 可以与不能做的解释

可以说：在同一固定读出与同一反事实设计下，强连续流效应只在 Instruct checkpoint 中出现，且跨 E/U 复现；这与“后训练建立或强化了连续声学流到情绪标签的任务读出”一致。

不能说：仅凭这组实验就证明某一具体 SFT 数据造成了效应，或证明 Base 不含情绪信息。Base 不是开箱即用的指令模型；上一轮逐层 tracing 已显示 Base 中间高层仍存在较弱的连续声学可读表征，只是最终四选一读出没有组织好。
